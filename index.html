    Flujo para publicar OTAs desde Arduino IDE
    1. Abre focos_c7/focos_c7.ino en Arduino IDE (placa NodeMCU 1.0 (ESP-12E Module) o Generic ESP8266 Module con Flash 4MB FS:2MB OTA:~1019KB).
    2. Edita el código y presiona Programa → Exportar binario compilado (Ctrl+Alt+S).
    3. Sube firmware.bin y version.json a GitHub (o ejecuta python publicar_ota.py) y presiona Actualizar por OTA aquí.
